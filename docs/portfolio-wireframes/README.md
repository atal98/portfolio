# Portfolio wireframes

This folder is the decision record for the portfolio's visual exploration.
It is intentionally separate from the live React application: no production
site code is changed while the direction is being decided.

## What is here

- `01-reference-synthesis.md` — the useful interaction and information-design
  principles observed in AuthKit, Belen Jones, and Unveil.
- `02-wireframe-plan.md` — the proposed portfolio structure and what each
  screen needs to prove.
- `03-execution-log.md` — a compact, dated record of what was produced and
  checked.
- `04-working-rules.md` — constraints for future wireframes and implementation.
- `05-implementation-plan.md` — the approved React implementation direction.
- `06-qa-report.md` — the implementation verification record.
- `07-authkit-research.md` — a reference study of AuthKit's visual-explanation
  pattern and the supplied screenshots.
- `08-system-story-pattern.md` — reusable visual proof modules for each
  portfolio project.
- `09-authkit-wireframe-plan.md` — the proposed visual grammar and adoption
  decision.
- `10-system-stories-implementation.md` — the delivered React system-story
  implementation and final QA record.
- `index.html` — a self-contained, responsive visual wireframe of the combined
  direction. Open it in a browser to review it.
- `authkit-system-stories.html` — a focused visual wireframe for the
  project-specific system story modules.

## How to review

1. Open `index.html` in a browser.
2. Assess the page as a flow, not as final styling: entry, selected work,
   project index, system explanation, contact.
3. Mark what to keep, remove, or combine before implementation begins.
