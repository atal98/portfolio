# Atal Upadhyay - resume template pack

## 01. ATS Application Resume

**File:** `Atal-Upadhyay-ATS-Resume.docx`

Use this version for job portals, careers pages, and agency uploads. It is single-column and text-first, with standard headings and labelled public hyperlinks. This is the default application file for both ATS parsing and AI-assisted recruiter screening.

## 02. Modern Technical Resume

**File:** `Atal-Upadhyay-Backend-Engineer-Resume.docx`

Use this version for direct recruiter messages, referral applications, and email introductions. It keeps the same evidence and links but adds restrained visual hierarchy and compact skill grouping.

## Use rules

1. Tailor the ATS version's summary, skills ordering, and strongest 3-5 bullets to the job description. Never add a skill or metric you cannot defend.
2. Keep the public links labelled as `Portfolio`, `LinkedIn`, and `GitHub`; they are clickable in both files.
3. Send DOCX when an application portal accepts or requests it. Export a PDF from Word or LibreOffice only after checking its page flow.
4. Do not upload the visual version in place of the ATS version on job portals.
