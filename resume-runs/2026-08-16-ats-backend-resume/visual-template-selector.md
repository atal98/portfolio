# Visual template selection

## Chosen profile: Modern Technical

This companion resume is for recruiter and referral sharing. It supports the candidate's backend, cloud, multi-tenant SaaS, and AI-workflow positioning with a strong left-aligned header, restrained blue accent, compact two-column technical-skill grouping, and experience-first hierarchy.

## Separation of surfaces

- `ats-resume.docx`: primary application file; single-column, text-first, low ATS risk.
- `designed-resume.docx`: recruiter/referral companion; uses the `modern-technical` profile and controlled tables only for summary and technical-skill grouping.

No profile photo is used. Public links are represented by clickable labels: Portfolio, LinkedIn, and GitHub.
